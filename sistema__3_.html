Importar Excel
⚠️ Importante: Este sistema guarda los datos en tu navegador (IndexedDB + localStorage). Si limpias el caché o abres el archivo en otro navegador, los datos se pierden. Usa el botón "Guardar datos" del menú superior para crear un respaldo .json después de cada importación.
🔗 Guardado automático en tu Excel maestro: Usa el botón "Vincular Excel" (arriba, en la barra superior) y selecciona tu archivo .xlsx (el mismo que importas). A partir de ese momento, cada vez que guardes un registro en "Captura", el sistema agrega una fila nueva en la hoja correspondiente (IMPRESION, LAMINACION, REFINADO, SIDE WELD o POUCH) de ese archivo, respetando sus columnas actuales — sin tocar ninguna otra hoja (rep-ov-espec, rep-dtll-ocmp, SEGUIMIENTO A OT), fórmulas ni formato.

Ten en cuenta:
  • Solo funciona en Chrome o Edge de escritorio (no Firefox, Safari ni celular).
  • Como tu archivo es grande (~46 MB), cada guardado puede tardar varios segundos mientras el navegador lo abre y reescribe completo.
  • Al reescribir el archivo, la librería que usamos (SheetJS) puede no conservar el 100% del formato, dibujos o comentarios originales — aceptaste este riesgo. Te recomendamos tener un respaldo del archivo por si acaso.
  • Si borras un registro dentro del sistema, eso NO se refleja en el Excel maestro (habría que borrarlo ahí manualmente); solo la captura de registros nuevos se sincroniza automáticamente.
